## 🏗️ Featured Projects

**☸️ Kube-Pilot — Production-Grade Kubernetes Platform on AWS**
> `Terraform` · `Amazon EKS` · `ArgoCD` · `Prometheus` · `Grafana` · `Loki` · `Kyverno` · `GitHub Actions`

Self-bootstrapping VPC and EKS infrastructure as reusable Terraform modules — full cluster provisioning in a single hands-off script (~15–20 min). GitOps continuous delivery with ArgoCD (App-of-Apps), cluster-wide security via 5 Kyverno admission policies, a full observability stack (Prometheus/Grafana/Loki), and validated horizontal autoscaling (1→5 pods) under k6 load tests.

**🍽️ [Feaston](https://feaston.iiitkottayam.ac.in) — Production Mess Coupon Management System**
> `Docker` · `PostgreSQL` · `Linux` · `Bash` · `Networking`

Dockerized full-stack web app deployed on the college Linux server, issuing meal coupons for 3,000+ students. Handles bursty, event-driven load (near-idle baseline spiking to 2,000+ concurrent users in a 1–2 hour window) using rate limiting and PostgreSQL indexing to stay stable under concurrent-login bursts.

**🛰️ Nlarge — Space Data Analysis Platform** · *NASA Space Apps Challenge 2024*
> `Docker` · `Python` · `Image Processing`

Designed the solution architecture and containerized the full stack for a 6-member team — earning **Global Nominee** status among 57,000+ participants. Built Python image-processing pipelines to analyze NASA space-imagery datasets.
